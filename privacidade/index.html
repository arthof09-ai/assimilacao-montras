Assimilação — Política de Privacidade

Última atualização: 9 de novembro de 2026

Esta página explica, de forma simples, como o jogo Assimilação trata os dados de quem joga. O jogo está em fase de protótipo.

Que dados são usados

Para entrar no jogo, você usa a sua conta do Google. Quando entra pela primeira vez, a sua conta do jogo é criada a partir dela. Os dados usados são só estes:

  • o seu nome da conta Google;
  • o seu e-mail da conta Google;
  • a sua foto da conta Google.

Eles servem apenas para você entrar no jogo e para o jogo saber quem é você quando voltar.

Onde ficam guardados

Esses dados ficam guardados só no seu aparelho (celular, computador ou outro), dentro do navegador que você usa para jogar.

Eles não são enviados para servidores nossos e não são partilhados com outras empresas nem com outras pessoas.

O que NÃO fazemos

  • Não vendemos dados de ninguém.
  • Não mostramos anúncios.
  • Não enviamos os seus dados para servidores nossos nem para terceiros.
  • Não usamos os seus dados para nada além de entrar no jogo.

Como apagar

Como os dados ficam só no seu aparelho, apagar é simples: basta limpar os dados do navegador (ou do aplicativo) onde você joga. Depois disso, a conta guardada naquele aparelho desaparece. Na próxima vez que entrar com a sua conta Google, uma conta nova é criada no aparelho.
